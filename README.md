# Zaroskill

Личный репозиторий навыков для требований, проектирования, проверки поведения и тестирования. Основные навыки независимы от языка, платформы и исходного Android-проекта. Здесь удобно редактировать инструкции, проверять изменения и переносить тот же набор на другой компьютер.

## Состав

| Навык | Назначение | Источник |

## Установка

Нужен Python 3.11+. Установщик и локальные проверки используют стандартную библиотеку. Из корня репозитория сначала посмотреть изменения:

```sh
python3 scripts/install.py
```

Установить четыре наших навыка в папку `skills` выбранного `CODEX_HOME` либо в `~/.codex/skills`:

```sh
python3 scripts/install.py --apply
```

На компьютере без Matt-плагина можно установить все шесть:

```sh
python3 scripts/install.py --with-matt --apply
```

Если Matt-плагин уже установлен, используй его экземпляры: установки четырёх наших навыков достаточно. Копии из `vendor/` нужны для переноса и воспроизводимости версии; две одновременно обнаруживаемые версии одного навыка могут давать разные инструкции.

Для обновления существующих, отличающихся копий нужны `--apply --replace`. Перед заменой установщик перемещает старую папку в `skill-backups/zaroskill-…` рядом с папкой установки. Он печатает путь резервной копии. Неизменившиеся навыки пропускаются. Проверка известных конфликтов выполняется до записи; применение и откат при ошибке переименования происходят отдельно для каждого навыка, не одной транзакцией всего набора.

Пример обновления только временной проверки:

```sh
python3 scripts/install.py --skill state-machine-verification --apply --replace
```

`--dest /path/to/skills` выбирает другую папку назначения. Исходники остаются в этом Git-репозитории; установленные папки — копии. После редактирования и проверки запускай установщик снова. Для обнаружения новых инструкций может потребоваться новый чат.

## Отладка и контроль версий

```sh
python3 -B scripts/check.py
python3 -B -m unittest discover -s tests -v
```

Первая команда проверяет упаковку, локальные ссылки, отсутствие привязки к домашней папке и неизменность Matt-снимков. Вторая проверяет установку, сохранение существующих файлов, резервное копирование и повторный запуск. Эти проверки не оценивают качество рассуждений агента.

- В [evals/state-machine-verification](evals/state-machine-verification/README.md) — случаи, исходные ответы и слепое сопоставление старой и обновлённой версии.
- В [evals/behavior-properties](evals/behavior-properties/README.md) — задания на реализацию, написание и оценку тестов, проверка внесённых ошибок и слепое сравнение уточнений о свойствах поведения.
- В [evals/khorikov](evals/khorikov/README.md) — ранее созданный переносимый стенд с ошибочными реализациями и эквивалентными рефакторингами. Локальная проверка fixtures работает без модели; генерация тестов и автономные исследования требуют авторизованного Codex CLI и расходуют его лимиты.
- В [правилах работы над репозиторием](AGENTS.md) — как проверять изменения навыков. Исторические результаты приложения не включены в переносимый пакет.

Репозиторий содержит исходный импорт и последующие изменения отдельными коммитами. Remote автоматически не создаётся. Итоги текущей проверки записаны в [VALIDATION.md](VALIDATION.md).

## Перенос на другой компьютер

Можно скопировать всю папку вместе с `.git`. Для переноса Git-истории одним файлом:

```sh
git bundle create zaroskill.bundle --all
```

Перенеси файл, затем на втором компьютере:

```sh
git clone /path/to/zaroskill.bundle zaroskill
cd zaroskill
python3 scripts/install.py --with-matt
python3 scripts/install.py --with-matt --apply
```

Если навыки уже существуют и отличаются, сначала сравни изменения; для подтверждённой замены добавь `--replace`. Для агента вне Codex можно передать путь к нужному `SKILL.md`; сохраняй всю папку навыка с его относительными ссылками и лицензией Matt, если переносится его пакет.

В `dist/zaroskill.bundle` хранится отдельно обновляемый снимок Git-истории. После новых коммитов обновляй его командой `git bundle create dist/zaroskill.bundle --all`; каталог `dist/` исключён из Git.
