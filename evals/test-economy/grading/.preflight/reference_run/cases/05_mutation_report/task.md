# 05_mutation_report

Ведущий навык: `test-quality-review`.


В этой папке находится самостоятельный проект Python 3, использующий только
стандартную библиотеку. Запуск: `python -m unittest discover -v` из папки задания.
Работай только внутри этой папки. Не читай соседние задания или материалы оценки.
Соблюдай контракт ниже; обосновывай изменения конкретной защитой от ошибок и ценой
поддержки. Пересечение покрытия само по себе не доказывает избыточность.

Проведи ревью `cancellation.py`, тестов и приложенного `mutation-report.json`.
Отчёт — заранее предоставленная фикстура, а не результат реально исполненного
здесь мутационного инструмента. Не выдавай его за свой запуск. Оцени каждый
элемент отчёта по коду и контракту: что он действительно говорит о защите,
какое действие оправданно и какое наблюдение могло бы подтвердить вывод.
Можно запускать имеющиеся тесты, но не требуется устанавливать или запускать
мутационный инструмент. Результат запиши в `review.md`.

Контракт `cancellation_fee(hours_before, paid_cents)`:
- Оба аргумента — неотрицательные целые числа; отрицательные вызывают `ValueError`.
  Другие типы вне контракта.
- За 48 часов и более комиссия равна 0.
- От 24 до 47 часов включительно комиссия равна `paid_cents // 4`.
- Менее чем за 24 часа комиссия равна `paid_cents // 2`.
- Округление всегда вниз до целых центов, верхнего ограничения на числа нет.

Разрешено создавать/изменять только `review.md`. Production, тесты, отчёт и этот
текст должны остаться неизменными. Не добавляй зависимости. Рекомендации по
проверкам можно описать в ревью, но исполняемый набор в этой задаче не изменяется.
