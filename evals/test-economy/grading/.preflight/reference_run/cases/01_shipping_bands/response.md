Сохранил различия между отрицательной суммой, допустимым нулём и обеими сторонами
каждого ценового порога. Внутренние примеры 1200/2400, 5500/7500 и 12000/20000
проверяли те же правила без указанной отдельной истории ошибки. Их удаление
сокращает повторяемые ожидания, а именованные subTest сохраняют диагностику границ.
Это один допустимый компактный набор, а не требование иметь заданное число методов.
