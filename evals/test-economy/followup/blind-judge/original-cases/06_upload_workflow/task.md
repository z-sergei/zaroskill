# 06_upload_workflow

Ведущий навык: `state-machine-verification`.


В этой папке находится самостоятельный проект Python 3, использующий только
стандартную библиотеку. Запуск: `python -m unittest discover -v` из папки задания.
Работай только внутри этой папки. Не читай соседние задания или материалы оценки.
Соблюдай контракт ниже; обосновывай изменения конкретной защитой от ошибок и ценой
поддержки. Пересечение покрытия само по себе не доказывает избыточность.

Нужно усилить тесты жизненного цикла асинхронной загрузки. Проверь временные
свойства на различающих последовательностях, сохраняя понятную диагностику и
разумную стоимость набора. Production уже реализует приведённый контракт и
меняться не должен. В `response.md` объясни, какие порядки событий различаются
тестами, почему выбранных последовательностей достаточно для обнаруживаемых
рисков и какую проверку ты выполнил.

Публичный контракт `UploadSession`:
- Новая сессия: `state == "idle"`, `result is None`.
- `begin()` из `idle`, `done` или `cancelled` начинает новую попытку: состояние
  `waiting`, результат `None`, возвращается положительный целочисленный id.
  Каждый успешный begin этой сессии возвращает id строго больше предыдущего.
- `begin()` в `waiting` вызывает `RuntimeError`; состояние, результат и активная
  попытка сохраняются.
- `complete(attempt_id, value)` принимает целочисленный id и строку-результат.
  Только для активного id в `waiting` он возвращает True, переводит сессию
  в `done` и сохраняет `value` как `result`.
- Любое другое завершение (чужое, устаревшее, повторное или вне ожидания)
  возвращает False и не меняет состояние/результат/активную попытку.
- `cancel()` в `waiting` возвращает True, переводит в `cancelled` и оставляет
  результат `None`. В остальных состояниях возвращает False без изменений.
- События вызываются последовательно; потокобезопасность, время и I/O вне задачи.
  Только `state`, `result` и названные методы — публичный API.

Разрешено изменять только `test_upload.py` и создавать/изменять `response.md`.
Не изменяй `upload.py`, этот текст или другие файлы. Не добавляй зависимости,
фреймворк проверки моделей или новый production API.
