# 02_display_name

Ведущий навык: `khorikov-unit-testing`.


В этой папке находится самостоятельный проект Python 3, использующий только
стандартную библиотеку. Запуск: `python -m unittest discover -v` из папки задания.
Работай только внутри этой папки. Не читай соседние задания или материалы оценки.
Соблюдай контракт ниже; обосновывай изменения конкретной защитой от ошибок и ценой
поддержки. Пересечение покрытия само по себе не доказывает избыточность.

Команда готовится менять интерфейс ввода имени и хочет дополнительную защиту
валидации. Оцени существующие тесты: если есть конкретный пробел в контракте,
закрой его; если защита уже достаточна, мотивированный вывод без добавлений допустим.
Production-код здесь не меняется. В `response.md` укажи, какие риски покрыты,
какие изменения ты сделал и какую проверку действительно выполнил.

Контракт `clean_display_name(raw)`:
- Вход — строка Python; другие типы вне контракта.
- Удаляются начальные и конечные пробельные символы по правилам `str.strip()`.
- После очистки длина от 1 до 20 символов включительно; иначе `ValueError`.
  Длина — `len()` строки Python, не байты и не графемы.
- Регистр и все символы внутри очищенной строки сохраняются без изменений.

Разрешено изменять только `test_names.py` и создавать/изменять `response.md`.
Не изменяй `names.py`, этот текст или другие файлы; не добавляй зависимости.
