# 01_shipping_bands

Ведущий навык: `khorikov-unit-testing`.


В этой папке находится самостоятельный проект Python 3, использующий только
стандартную библиотеку. Запуск: `python -m unittest discover -v` из папки задания.
Работай только внутри этой папки. Не читай соседние задания или материалы оценки.
Соблюдай контракт ниже; обосновывай изменения конкретной защитой от ошибок и ценой
поддержки. Пересечение покрытия само по себе не доказывает избыточность.

Сопровождающий проекта просит упростить тесты расчёта доставки, сохранив защиту
контракта. Проверь набор и внеси оправданные изменения. Не меняй production-код.
В `response.md` объясни сохранённые различия и причины сокращения или сохранения
примеров; укажи реально выполненную проверку.

Контракт `delivery_fee(subtotal_cents)`:
- Вход — целое количество центов; другие типы вне контракта.
- Отрицательное значение вызывает `ValueError`.
- Для суммы от 0 до 4999 включительно доставка стоит 500 центов.
- Для суммы от 5000 до 9999 включительно доставка стоит 250 центов.
- Для суммы от 10000 доставка бесплатна, верхнего ограничения нет.

Разрешено изменять только `test_shipping.py` и создавать/изменять `response.md`.
Остальные файлы, включая `shipping.py` и этот текст, должны остаться неизменными.
Не добавляй зависимости, новый тестовый фреймворк или отдельную архитектуру.
