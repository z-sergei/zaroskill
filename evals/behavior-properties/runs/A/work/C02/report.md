# C02 — тесты SearchApp

Добавлен только test_search.py; search.py не менялся (проверен исходный SHA-256). Все 3 теста прошли: `python3 -m unittest discover -v`.

Покрытие и свойства:
- Каждый search отправляет ровно один `(token, query)` на gateway; возвращённый token совпадает с переданным в запросе. Активный ответ показывает ожидаемые результаты.
- Новый поиск сохраняет предыдущую выдачу до ответа; пустой активный ответ очищает её.
- Для двух последовательных поисков выполнены оба порядка завершений. После каждого события проверяется visible: старый ответ не меняет её ни до, ни после активного ответа.

Spy оправдан внешней границей gateway; решения выполняет настоящий SearchApp. Нет привязки к числам, внутреннему счётчику, порядку вспомогательных вызовов или потокам. В отдельной копии снятие проверки активного token вызвало 2 ожидаемых отказа; замена числовых token на свежие object() сохранила все 3 теста зелёными. Исходный набор повторно прошёл. Это проверки существующего поведения, не заявление о test-first разработке production.

Граница доказательства — запуск запроса на порте и обработка явно поданных ответов до публичного visible. Реальный сетевой протокол, фактическая UI-отрисовка и произвольные длинные истории не проверялись и этой фикстурой не обещаны. Все команды и результаты сохранены в evidence.md; блокировок нет.
