# Проверка дополнений к state-machine-verification

24 октября 2026 года. Сравнение исходной и обновлённой версии на десяти одинаковых случаях разработки. У каждой версии был отдельный агент со свежим контекстом; независимый судья видел только случаи, заранее записанную рубрику и ответы A/B. При оценке он не знал, какой ответ относится к обновлению. После заключения раскрыто: **A — исходная, B — обновлённая**.

Результат: **ничья**. Обе версии обнаружили четыре существенные проблемы, не пропустили ни одной из предусмотренных и не сделали ложных замечаний на шести здоровых случаях. Ни одна не навязала формальную модель простой функции и не вышла за аналитический объём задания.

| Материал | Назначение |
| --- | --- |
| [cases.md](cases.md) | Все десять запросов и исходные факты |
| [rubric.json](rubric.json) | Критерии, зафиксированные до запуска |
| [answer-A.json](answer-A.json), [answer-B.json](answer-B.json) | Неотредактированные ответы агентов |
| [judgment.md](judgment.md), [judgment.json](judgment.json) | Независимая оценка до раскрытия версий |
| [protocol.json](protocol.json) | Условия, соответствие A/B и хеши входных инструкций и результатов |

Дополнения сохранены по запросу пользователя как явно изложенные условные приёмы: достаточность информации, восстановление и совместимость обещаний. Этот прогон не установил преимущество перед исходной версией. Он показывает отсутствие обнаруженных ухудшений только на этих конкретных ответах. Один запуск на версию и знакомые случаи разработки не дают статистической оценки надёжности.

В Git первый коммит содержит переносимый импорт до этих дополнений; из него уже исключена карта конкретного Android-проекта. Для A использовался исходный установленный пакет до этой корректировки упаковки. Точные хеши записаны; сама карта проекта в переносимый репозиторий не включена. Пакет текущей версии совпадает с входом B побайтно.

Чтобы продолжать отладку, сравнивай неизменённый контракт, одинаковые входы и одинаковые бюджеты. Добавляй новые реальные случаи и корректные контроли по наблюдаемым слабостям. Эти десять случаев уже являются материалом разработки, не новым скрытым набором. Сохраняй исходные ответы и оценивай материальные находки, ложные замечания, границы задания и силу свидетельств. Автоматической команды для повторения LLM-сравнения здесь нет: нужны отдельные свежие контексты и слепой судья по описанному протоколу.
